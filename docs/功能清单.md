## 一、感知

| 能力 | 状态 | 说明 |
|---|---|---|
| 看人脸 | ✅ | 摄像头 8 帧取最优，判断几个人、谁在看镜头、离得远近 |
| 头部朝向 | ✅ | 用同帧瞳距归一化，距离 1 米和 2 米读数一致，不用标定相机 |
| 感光 | ✅ | 用摄像头当光传感器（画面平均亮度），房间暗（<45）她会变困 |
| 听声音 | ✅ | 离线识别，whisper-small 主用 / vosk 备用 |
| 听语气 | ✅ | 音量（dBFS）+ 音高（自相关），和"你自己平时"比，不看绝对值 |
| 看屏幕 | ⚠️ | 截图 + 视觉模型已接好，**要配 vision_api_key 才能用** |
| 声纹（认声音） | 🧪 | 模型能跑，但跨说话人只差 0.09，**判不准，没有启用** |
| 被摸 | ❌ | 要触摸传感器；事件入口 `feel.event("petted")` 已留好 |
| 被抱起 | ❌ | 要加速度计；`"held"` / `"dropped"` 已留好 |
| 体温 | ❌ | 要加热片，而且这是"输出"不是"感知" |

| 语速随情绪 | ✅ | 精力低 → 140，兴奋 → 195 |
| 音高随情绪 | ✅ | 开心时 +12Hz |

## 九、已知限制（诚实清单）

1. **在线音色会被 TLS 拦**，随时退回本机机械音 —— 演示前要测
2. **声纹不可用**，只能用"叫名字"近似
3. **被摸、被抱、体温、动作** 全要硬件，现在只有接口
4. **看屏幕要额外 key**，没配就用不了
5. **身体抽象层没接进主流程**，还是各模块直连
6. **没在 RDK 上跑过**，只是"设计上能搬"
7. 三观访谈是 35—60 分钟的模式，容易被误触发
