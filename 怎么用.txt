汤圆 · 怎么用
================================================

【第一步：找到这个文件夹】

  1. 点屏幕最下面那排图标里的「笑脸」（Finder，蓝白色的）
  2. 窗口左边竖着的那一列，点「下载」
  3. 找到 robot-brain 这个文件夹，双击进去

  看到这些了吗：
      启动大脑.command          ← 平时用这个
      换音色.command            ← 想换声音用这个
      config.json              ← 装 key 的地方
      README.md                ← 详细说明
      agent 文件夹              ← 代码，不用管


【第二步：说话】

  双击「启动大脑.command」
  → 如果弹窗说「无法打开，因为来自身份不明的开发者」：
        右键点它 → 选「打开」 → 再点「打开」
    （只需要这样一次，以后直接双击）
  → 菜单里输 1（打字）或 2（语音）
  → 输 2 的话，第一次会问能不能用麦克风，点「允许」
  → 直接说话就行，不用按键


【第三步：换声音】

  双击「换音色.command」
  会先列 8 个在线音色（好听，要联网）：
        1  Xiaoxiao   晓晓 · 女 · 自然亲切
        2  Xiaoyi     晓伊 · 女 · 年轻活泼
        3  Yunxi      云希 · 男 · 年轻温和
        ...
  再列 3 个本机音色（不联网，机械一点）。
  → 输入编号，回车，它会念一句给你听
  → 觉得好听就输 y，回车
  → 完事。下次启动就是新声音了

  断网了也不怕：在线音色连不上，它会自动退回本机音色。

  不用手动改任何文件。它会自己改好 config.json。


【识别引擎】

  config.json 里有一行 "asr": "whisper"。
    whisper —— 默认，准一些，模型 460MB
    vosk    —— 老模型 44MB，快，但容易错字
  改这两个字，存盘，重开就换。


【想自己改配置的话】

  1. 右键点 config.json → 选「打开方式」→「文本编辑」
  2. 你会看到一堆这样的行：
         "voice": "Meijia",
         "model": "deepseek-chat",
    只改引号里面的内容，别动引号和逗号
  3. 按 Command + S 保存
  4. 关掉窗口，重新双击「启动大脑.command」

  ⚠️ config.json 里有你的 API key。
